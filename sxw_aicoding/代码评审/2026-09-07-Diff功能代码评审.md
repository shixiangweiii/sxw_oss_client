### 2. 主进程扫描与 IPC（方案第二节）——✅ 完全符合

- **独立只读服务**：`DiffManager`（diff.ts）+ `diffFiles.ts`（纯读取函数），不触碰同步传输/临时文件/写探测。复用 `prepareRoot(create=false)`（根目录缺失报错不创建）、`validateKey`、`maybeStat`、`sameFile`、`checkCancelled`。
- **扫描流程**：连接快照 → 分页列举（含游标有效性/重复 key 防御）→ 文本候选 → 本地定位（跳过符号链接、越界、同步临时目录、文件/目录冲突、大小写冲突、多 key 映射同一本地路径整体记冲突）→ **3 个 worker 并发**限长读取比较 → 只保留路径/大小/时间/指纹（正文即读即弃）。
- **读取一致性**：本地 fd `O_NOFOLLOW` + 读取前后 inode/mtime/ctime/size 三重校验；云端 HEAD 拿 etag/versionId → `If-Match` 条件 GET + Range 限长 → 响应 etag/versionId 比对 + 长度比对。变化即记失败并继续。
- **IPC 四步登记**：`shared/constants.ts`（9 个通道）→ `shared/types.ts`（类型挂到 `ElectronAPI`）→ `main/ipc.ts`（经 `registerDiffIpcHandlers` 注册，缓解了"第 3 步无类型关联"的老问题）→ `preload/index.ts` 暴露。**完全遵守项目约定。**
- **安全边界**：渲染层只传 `taskId / key / requestId`；`read()` 校验 key ∈ `session.allowed`（白名单），无法借 diff 接口读任意路径；`requestId` 长度校验。分页 offset 做 `Number.isSafeInteger` 校验。

## 三、发现的问题与建议（按重要程度排序，均为非阻塞）

### P1. DiffEditor 的版本兼容检查在 useEffect 中 throw，Error Boundary 接不住

- **位置**：`src/renderer/components/DiffEditor.tsx:60-61`（`throw new Error('Monaco 版本不支持差异计算状态…')`，以及同 effect 内 `createDiffEditor` 可能的抛错）
- **问题**：React 的 Error Boundary（此处 `EditorBoundary`）只捕获**渲染期**错误，不捕获 `useEffect` 中抛出的异常。该防御路径一旦真正触发，结果是未捕获异常（控制台报错、组件树可能白屏），而不是预设的"对比视图加载失败，请返回后重新打开"。
- **风险**：低（`monaco-editor` 已精确锁定 0.56.0，正常运行不会触发），但这属于"防御代码本身失效"的问题。
- **建议**：把能力检测移到模块顶层或组件渲染期（渲染期 throw 才会被 Boundary 捕获），或在 effect 中改为 `setError` 状态。

### P2. 大 Bucket 下扫描配对阶段的系统调用开销（性能提示）

- **位置**：`src/main/diffFiles.ts` `locateDiffFile`（每层 `checkDiffRoot` lstat 根目录 + `readdir` 整个目录再线性查找名称）；`src/main/diff.ts` 配对循环对每个云端 key 逐一调用；`readDiffPair` 读取前后又各走一遍完整路径解析。
- **问题**：配对阶段为 O(对象数 × 路径深度) 次 `readdir`/`lstat`，且每次 `locateDiffFile` 开头都先 `lstat` 根目录一次。10 万级对象的 Bucket 配对阶段会明显偏慢（纯元数据操作，无网络，尚不至于不可用）。目录名 `names.find(...)` 的 NFD 归一化对大目录也是逐项字符串运算。
- **建议**：后续可为"单次扫描"缓存每层目录的 `readdir` 结果与根目录 stat（扫描本身是只读快照语义，缓存风险可控）；根目录校验频率也可降为阶段性抽查 + 比较完成后一次终检（现有终检已在）。首版不改可接受。

### P3. 分页接口每次全量重排序（性能提示）

- **位置**：`src/main/diff.ts:170` `page()` —— 每次 `getOssDiffEntries/Issues` 都 `[...values].sort(byKey)`。
- **问题**：每次翻页 O(n log n)。差异条目数千以内无感知；若某目录差异上万，翻页会有可感延迟。
- **建议**：终态后条目集合基本只减不增，可在扫描完成时生成一次排序数组，后续读取走二分定位；或维持 Map 插入顺序（云端 key 本已按字典序遍历，自然有序）。

### P4. `openDiffFile` 入口缺少 busy 前置检查（一致性建议）

- **位置**：`src/renderer/store/diffSlice.ts:168`。
- **问题**：列表按钮已按 `snapshot.busy || syncBusy || pending` 禁用，但 action 层可直接调用；此时错误来自主进程 `reserveDiff()`，以红色错误形式落进详情页。与 `startDiff`（入口有多条件防御）风格不一致。
- **建议**：入口补 `if (get().diffSnapshot.busy) return`（或给出提示）。低风险，UI 已兜底。

### P5. Diff 期间其他窗口"刷新配置"被闸门拦截（设计取舍确认）

- **位置**：`src/main/oss.ts:96`（`getDefaultBucket` 中 `assertSyncIdle()`，现包含 `diffRunning`）。
- **问题**：Diff 扫描/单文件读取期间，任何窗口的配置刷新（bootstrap）都会报"Diff 正在读取…"。这与同步期间的既有语义一致，但 Diff 扫描持续时间通常远长于单文件同步，互斥面实际被放大。
- **建议**：确认这是预期取舍（方案只要求与同步/在线保存互斥）；若后续反馈 UX 问题，可考虑把纯读的配置重载与写操作闸门解耦。

### P6. 小的风格问题（不影响功能）

- `src/renderer/store/types.ts:1-8`：连续两条 `import type` 自同一模块 `'../../shared/types'`，可合并（lint 未拦截）。
- `src/main/diffFiles.ts` `readRemote` 的 `Range: bytes=0-${MAX_TEXT_DIFF_BYTES}` 语义上是 0–2097152（含端点，即最多 2097153 字节），靠 `bytes.length !== size` 兜底校验。正确性无问题，写成 `MAX - 1` 更精确。
- `src/renderer/components/DiffPage.tsx` `closeDiff` 后 `diffPage` 未归零（`startDiff` 会重置、`loadDiffPage` 会钳制，无用户可见影响，仅状态卫生）。

### P7. 包体积提示

- `DiffEditor` 懒加载 chunk 约 6.0 MB（Monaco + base64 内联 Worker），首次打开对比页有短暂加载；主包仍保持 293 KB。属方案选型（内联 Worker + 全量打包）的预期取舍，本地加载无实际痛点，留档知悉即可。

## 四、值得肯定的实现细节

1. **一致性校验链条严谨**：本地读取采用 fd 直读 + 前后双 stat（inode/size/mtimeNs/ctimeNs）+ 读取后重新走路径解析，云端 HEAD/GET 之间用 If-Match + etag/versionId 双重比对，能可靠识别"读取期间被替换"。配套测试用 fs 代理真实模拟了读取中途篡改。
2. **路径与别名处理周全**：Unicode NFD/大小写别名、硬链接（同 inode 不同名仍按各自路径比较）、多云端 key 映射同一本地文件时整体记冲突不任意选择——这些边界都有针对性测试且在 macOS/大小写敏感卷上分别断言。
3. **闸门无 TOCTOU**：`reserveDiff` 检查与置位之间无 await，延续了 `reserveSync` 的关键约定。
4. **渲染层代次防护完整**：`epoch/reads/pages/issues` 四计数器 + `taskId` 比对，翻页乱序、快速切换文件、关闭后迟到响应均有测试覆盖。
5. **Monaco 集成符合官方 ESM 建议**：单一 editor worker、`createViewModel` 复用计算结果、通过运行时探测 `quitEarly` 识别超时（对 0.56 内部 API 的类型断言并带版本锁与能力检测），烟测真实验证了 blob Worker 的消息收发与 CSP 无告警。
6. **中文文案、macOS 优先、Tailwind 暗色、依赖分区**等项目约定全部遵守；注释解释了"为什么"而非"是什么"（如 fd 保留到校验结束的原因、目录/文件别名识别策略的差异）。
